# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？

チーム全体でデータを共有するためにサーバー上に配置された保管場所で、ローカルリポジトリは開発者が自分自身のパソコン上で直接作業を行うために持つ保管場所。

## プッシュとマージの違いは何でしょうか？

プッシュは「自分のパソコン（ローカル）にある変更履歴を、インターネット上の共有場所（リモートリポジトリ）へアップロードする作業」です。一方、マージは「枝分かれした作業履歴を一つに合流させる作業」を指します。

## コミットとプッシュの違い

「自分のパソコン（ローカル）に保存するか」「インターネット上のサーバー（リモート）にアップロードするか」という点です。

## コミットのメッセージはどのように書いてあげるのが最適でしょうか？

何を（What）」「なぜ（Why）」を簡潔に伝え、将来の自分やチームメンバーが変更履歴をスムーズに追えるように書くのが最適です。

## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？

ローカルでのマージは自身のPC内で行う作業です。一方、プルリクエスト（PR）を利用したフローは、GitHubなどのリモートリポジトリ上で他者にコードの変更を提案し、レビューと承認を経てからマージを行うチーム開発の標準的な手法です。

## コンフリクトを起こしてしまった場合、どう対処すべきですか？
冷静になり、事実を整理する
感情を切り離し、「何が原因で揉めているのか」という事実だけを特定します。

相手の言い分を最後まで聞く
反論せずに傾聴し、相手が本当に求めている「背景や本音」を理解します。

共通のゴールを再確認する
「やり方は違っても、目指す目的（売上、品質向上など）は同じ」という共通認識を持ちます。
